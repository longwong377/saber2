# Reference images — drop them here

Every folder below is empty on purpose and is **read by a person, not by the
game**. Nothing in here is fetched at runtime, nothing is bundled, and nothing
breaks if a folder stays empty forever. Drag images in from the GitHub web UI
(*Add file → Upload files*) or commit them normally.

## Why the folders are split this way

A reference is only useful if it answers a question that was actually open. The
split below is by **question**, not by subject — so when work starts on the
Kamino platforms the folder to open is obvious, and an image that answers
nothing has nowhere to go.

| Folder | The question it answers |
|---|---|
| `maps/geonosis` | The First Battle of Geonosis — ground, spires, arena, the look of the army fronts. **Highest value right now**: the Command mode is built on this. |
| `maps/coruscant-temple` | The Jedi Temple, inside and out. Halls, the Archives, the Council chamber, the spires. |
| `maps/mustafar` | Actual Mustafar — lava falls, the mining complex, the black obsidian shore, the sky. |
| `maps/kamino` | Tipoca City — the platform stalks, the sea state, the rain, the interiors. |
| `maps/flagship` | A Separatist/Republic capital ship interior — hangar, bridge, corridors, the scale. |
| `maps/colosseum` | Crowd tiers, alien spectators, the stone. |
| `maps/drowned-wood` | Cel-shaded swamp/forest — **especially the ground and undergrowth**. |
| `maps/alpine` | Snow and rock that is *not* desert rock. |
| `maps/dunes` | Dune shapes, sandstorm, the horizon. |
| `units/clones` | Phase I/II armour, rank markings, specialists, jet troopers, ARC, commandos. |
| `units/droids` | B1, B2, BX, droideka, MagnaGuard, tactical droid, rocket droid. |

## What actually helps

Ranked, from what has moved the needle in this project before:

1. **Wide shots that establish a place.** A single image of a horizon does more
   for a level than ten close-ups of a prop, because the thing that keeps
   failing is *the feeling of being somewhere* — not the detail of any one
   object.
2. **Ground and undergrowth close-ups.** The grass has been rebuilt three times
   and is still the weakest surface in the game. One good cel-shaded ground
   reference is worth a paragraph of description.
3. **Silhouettes.** For creatures and troops, the outline is the whole read at
   the distance you actually fight them.
4. **Anything that shows how *stylised* is meant to land** — the game is
   cel-shaded, so a photoreal render is a weaker reference than a piece of
   concept art or a frame from an animated series.

Screenshots **of this game** with a note on what is wrong are just as valuable
as the reference; put those in `misc` or beside the map they belong to.

## Naming

No scheme is enforced. `kamino-rain-01.jpg` beats `IMG_4471.jpg` only because it
is easier to talk about in a message. Sub-folders are fine.
